# Новичок

Приложение для HR, которое помогает разобрать отзывы сотрудников о первой неделе работы. Модель предлагает одну из шести тем, а сводка показывает, какие трудности повторяются по подразделениям. HR может открыть исходный отзыв и поправить тему.

## Запуск

Проект собран на Python 3.11.3. Из корня репозитория в PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

На Linux или macOS используйте `python3.11 -m venv .venv` и `.venv/bin/python` в двух следующих командах. Откройте адрес из строки `Local URL` в терминале.

## Как посмотреть демо

1. Нажмите **«Загрузить пример»**. Откроются 32 вымышленных отзыва от сотрудников склада, магазинов, отдела продаж и офиса.
2. Выберите **«Магазины»** и тему **«Обучение и практика»**. Четыре из восьми отзывов относятся к обучению, три из них упоминают оформление возвратов.
3. Выберите **«Все подразделения»**, затем **«Требуется ручной разбор»**. Откройте `DEMO-001`, поставьте тему **«Доступы и инструменты»** и сохраните. Отзыв исчезнет из очереди, а сводка обновится. Новую тему и исходный прогноз можно увидеть в списке **«Все темы»**.

Можно загрузить свой CSV в UTF-8 с разделителем-запятой и столбцами `feedback_id`, `department`, `text`. Идентификатор каждого отзыва должен быть уникальным. Ручные правки хранятся в текущей сессии.

## Модель и проверка

Модель обучена на 96 синтетических отзывах. TF-IDF по символьным n-граммам передаёт признаки в логистическую регрессию. Если максимальная оценка модели ниже `0.21`, отзыв отправляется на ручную проверку. На демонстрационных данных в эту очередь попадают 8 из 32 отзывов.

На 24 размеченных синтетических отзывах исходный классификатор правильно определил тему в 20 случаях. **Macro-F1 — 0,841**. В `data/test.csv` есть ещё шесть неоднозначных отзывов без меток. Они исключены из расчёта метрик. Качество на реальных отзывах и влияние на ранние увольнения остаются открытыми вопросами.

## Файлы

| Файл | Назначение |
| --- | --- |
| `app.py` | Интерфейс Streamlit |
| `model.joblib` | Обученный пайплайн для запуска приложения |

Чтобы повторить обучение, откройте `test.ipynb` в VS Code, выберите ядро из `.venv` и запустите все ячейки. Рабочая папка ноутбука должна совпадать с корнем репозитория. При выполнении ячейки сохранения `model.joblib` будет перезаписан.
